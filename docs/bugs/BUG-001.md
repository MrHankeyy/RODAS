# BUG-001：数值输入框的上下调节箭头不可见

- 记录日期：2026-10-20
- 状态：待修复（用户报告，尚未独立复现）
- 模块：方案配置 / 数值输入控件
- 环境：Windows；用户此前使用 v0.1，本次截图的具体版本待核对。

## 复现步骤

1. 进入【方案配置】，选择【两水平筛选设计】。
2. 查看【报告重点主效应数】输入框右侧的上下调节按钮。
3. 检查其他同类数值输入框。

## 实际表现

上下调节箭头不可见。用户反馈其他同类控件也存在此现象；具体范围及点击功能是否受影响待核查。

## 预期表现

上下箭头清晰可见，能够辨认递增、递减操作。
