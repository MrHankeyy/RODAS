# SVR 固定参数搜索范围的精度限制

固定双盆地算例使用 160 个最优 LHS 样本、采样种子 19、训练划分种子 2027。
原显式回归脚本对三种模型均要求测试集 R² > 0.60；原参数下 SVR 为 0.5422，仍未满足该断言。

| 模型/设置 | 测试集 R² | 归一化平均绝对误差% |
|---|---:|---:|
| Kriging（一次趋势） | 0.8707 | 1.0908 |
| SVR：C=1～10，步长3；γ=0.01～2，步长0.5 | 0.5422 | 2.2021 |
| SVR：C=1～100，步长11；γ=0.01～5，步长0.25 | 0.6734 | 1.7256 |
| ANN：两层、每层16节点、tanh、300代 | 0.6723 | 2.4189 |

两组 SVR 均使用真实 scikit-learn SVR；扩展范围时选中 C=100、γ=4.76。
该对照说明此算例的预测精度依赖参数搜索范围，不能据此保证其他数据的精度。
三种代理驱动的鲁棒优化链路检查均通过，推荐点在宽谷 (2,2) 附近。
软件在测试集 R² < 0.60 时显示精度提醒，不静默切换模型。

原精度断言及失败记录保存在外部最终核验材料中。未调整默认参数、降低原断言阈值或将该失败记为通过。
