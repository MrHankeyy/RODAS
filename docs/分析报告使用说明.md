# 当前结果报告使用说明

1. 保存问题定义，配置试验方案并回填响应。
2. 田口设计计算水平效应、信噪比和候选水平；响应曲面或代理模型方案计算模型统计量与优化结果。
3. 在“分析报告”预览当前结果。项目名称、编制人均为选填。
4. 导出 PDF 或 HTML，报告直接使用已计算结果。

再次计算替换当前结果，不保存操作履历。问题定义或试验数据改变后，需要重新计算。
优化设置尚未执行的修改属于草稿；任务文件和报告保留上一次已计算结果及其对应设置。

底部消息面板统一显示成功、提醒、失败和迭代进度，支持筛选与清空；消息仅在本次会话保存，最多 500 条。

报告包含模型适用范围、约束可行性和确认建议。田口候选依据主效应假设，连续优化候选依据当前模型；两者均需独立确认。
