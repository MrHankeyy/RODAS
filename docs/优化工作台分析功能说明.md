# 优化工作台分析功能说明

## 入口与页面分工

- 数据管理的“数据录入”维护试验记录，“数据分析”合并完整度检查和描述统计。跨设计点的响应分布不代表固定工况下的随机分布。
- 优化设计的“方案与结果汇总”上半区展示模型构建设置，点击“代理模型构建”后在下半区查看建模结果总览；不执行鲁棒优化。
- 模型与数据分为“统计检验、验证与残差、模型与系数”，承接对应总览分组的详细结果。
- “鲁棒性优化设计”上半区设置优化策略和遗传算法参数，下半区保留“方案对比、波动核验”两组推荐解摘要及详情入口；移除右上角状态蓝框，使用取值/响应表和方差份额比例条展示，不再展示推荐设计指标卡片。
- “优化结果”下设“方案对比、波动核验”两个详情页。原“参数取值”和“优化工具集”已删除，局部方差贡献迁入波动核验。
- 导航随任务切换；因子筛选、田口分析沿用专用流程，不送入连续鲁棒优化器。

## 建模结果

| 页面 | 内容与适用范围 |
| --- | --- |
| 统计检验 | 回归、残差、总平方和，回归整体显著性，重复点纯误差与失拟检验；缺少自由度或纯误差时显示不可估计原因 |
| 验证与残差 | 训练或留出验证误差、留一及分折验证、四联图；同一输入的观测均值与预测值配竖向组内标准差误差棒，其余诊断图保留逐次残差 |
| 模型与系数 | 编码变量方程、实际变量编码关系、系数估计与标准误、t/p及95%区间 |

系数推断适用于满足相应假设的可识别OLS回归，不给Kriging、SVR、ANN套用回归系数检验。逐项p值未作多重比较校正。留一验证通过帽子矩阵计算，删除点后不可识别时不报告。诊断图各自保留中文、英文与用途悬停。

## 鲁棒优化策略

- **多目标优化（帕累托）**：同时优化目标表现与波动，展示本次实际求得的帕累托前沿和默认折中推荐方案。
- **波动约束优化**：为每个目标响应填写允许的最大标准差，原单位的σ上限与原有响应性能约束同时生效，优化目标均值表现。
- **加权目标优化**：按设置的权重汇总目标表现与波动。

性能约束裕度系数固定为k=1。设计变量的区间不确定性按均匀分布换算，半宽为δ时输入标准差为δ/√3，等价于全宽/√12；概率不确定性按配置的分布计算。界面不再提供这两类系数的手动输入。

遗传算法支持种群数、代数、随机种子、逐变量交叉概率、自动或手动逐变量变异概率以及交叉/变异分布指数。父代精英保留与选择遵循可行性优先，目标改善不能抵消约束违反。

## 方案对比

- 多目标策略列出本次优化返回的实际帕累托方案；点击图上前沿点、方案表“查看”或方案选择器可切换当前方案。
- 单个目标响应时，前沿横轴为该响应的鲁棒均值、纵轴为标准差，均使用原单位；多个目标响应时使用求解器汇总的均值损失与归一化标准差。
- 波动约束和加权目标策略展示本次实际返回的单个方案。未找到可行方案时明确标识，不标为可行推荐。
- 下部展示当前方案的设计变量、输入标准差、全部响应的角色及近似均值/标准差，并集中展示性能约束及标准差上限的核验结果。两个详情页同步切换查看方案，总览始终展示默认推荐解。从总览点击详情时打开推荐解。查看操作不重跑优化，不更改默认推荐。
- 已删除400点随机候选比较、逐因子扫描图以及最陡改进、EVOP、AOFAT等局部探索的算法、调用入口、结果字段与报告内容。

## 波动核验

- 按当前查看方案和所选响应展示局部方差贡献，含各输入因子及模型残差；份额以百分比和进度条显示。
- 模型残差是观测与拟合之间的残差方差估计，包含试验随机误差及可能的模型失拟，不归入某一个输入因子。
- 分解沿用优化器的独立输入、局部对角二阶近似，包含一阶项和对角曲率项，不计混合二阶项，不代表全局因子重要性。
- 约束核验已移至“方案对比”，逐项展示计算值、允许范围、余量、判定及单位，波动约束策略额外展示各目标的标准差上限核验。余量为负表示违反约束。
- **μ±kσ是局部矩近似下的稳健带，不是均值置信区间或预测区间，不保证指定概率覆盖。**

## 保存、导出与失效

- 统计及系数表保留CSV导出，诊断图保留PNG/SVG导出，完整分析JSON记录实际模型、统计、优化结果及默认推荐点方差分解，不再写入已删除的探索结果。
- .rodas保存实际优化快照与当前查看方案序号。恢复后重建结果展示，不重新拟合或求解。正式报告仍采用求解器默认返回方案，查看其他方案不会悄悄替换报告对象。
- 输入、数据或配置变化后按现有规则清理失效展示；后台计算若对应输入已过期，完成时丢弃过期结果。
