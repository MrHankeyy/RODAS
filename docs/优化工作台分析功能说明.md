# 优化工作台分析功能说明

## 使用入口

- **整体数据分析 → 刷新数据统计（无需模型）**：响应未填全时也能查看有效数、缺失数、均值、样本标准差、五数概括、IQR、偏度和超额峰度。不同 DOE 点的响应分布不代表固定工况下的随机分布。
- **仅建模与统计分析**：使用当前方案训练/取得模型，然后输出统计结果，不执行鲁棒优化。代理模型沿用当前配置及有效的训练缓存；响应曲面使用完整二次模型。
- **执行稳定性设计与鲁棒优化**：运行现有优化，并同时更新统计、推荐点、因子扫描及参考点容差贡献。
- **统计诊断与导出**：选择响应，切换拟合统计、系数区间、逐点诊断、四联图和设计点核验。

## 新增和完善的分析

| 输出 | 含义与适用范围 |
| --- | --- |
| RMSE、MAE、最大绝对误差、R²、残差均值和标准差 | 响应曲面使用训练拟合结果；代理模型使用已保存的留出验证结果，界面明确区分 |
| 回归/残差/总平方和、回归 F/p、纯误差与失拟 F/p | 适用于可识别的 OLS 回归，缺少自由度或有效纯误差时不伪造检验结果 |
| 系数标准误、t、p、95%区间 | 基于独立同方差正态误差假设，p 值未作多重比较校正；编码变量与实际量纲的转换明确列出 |
| LOO PRESS、LOO RMSE、预测 R² | 用线性回归帽子矩阵计算留一误差；删除点后不可识别时不报告；另保留原 K 折验证说明 |
| 杠杆值、内部学生化残差、Cook 距离 | 用于定位高影响观测，不是自动删点依据；代理模型不输出不适用的 OLS 指标 |
| 四联图 | 实测与预测、残差与预测、残差正态 Q-Q、按数据行序的残差序列；行序不一定是实际试验时间 |
| 设计点核验 | 手动输入或载入优化返回点，显示名义预测、鲁棒均值、传播标准差、μ±kσ、逐响应约束余量及通过/违反状态 |
| 局部方差贡献 | 在优化返回点计算；未优化时取区间中心。包含一阶、对角二阶曲率和模型残差项，分解总量与当前优化器一致 |

系数推断不适用于 Kriging/SVR/ANN 等黑盒模型，因此不会给这些模型套用虚假的回归系数检验。误差数值上为零或残差自由度不足时，同样不显示虚假的 p 值和区间。

**μ±kσ 是局部矩近似下的稳健带，不是均值置信区间或预测区间，不保证指定概率覆盖。** 当前沿用优化器的独立输入、对角二阶近似，未计入混合二阶项。局部方差贡献不是全局因子重要性。

## 优化工具

最陡改进、EVOP 局部单因子试探、自适应 AOFAT 都直接调用当前模型。可以选择优化返回点、已核验的手动点或区间中心作为起点，并设置步数、相对跨度步长和均值权重 λ。

工具采用可行性优先：可行点之间比较加权损失，不让目标改善抵消约束违反；从不可行点出发时先降低约束违反量。每个试探点均展示变量值、望性、标准差、约束违反量、加权损失及可行状态。最陡改进在归一化变量空间计算方向，并回溯检查改善，避免量纲差异导致步长错误。

这些工具输出模型辅助的局部候选，不保证全局最优，也不是已经完成的实测 EVOP 试验。参数设计中的“稳定候选”是有限抽样内找到的可行点；没有可行候选时明确显示未找到。

## 导出与刷新

- 当前统计表导出为 UTF-8 CSV。
- 完整分析导出为 JSON，包含输入/响应定义、数据指纹、生成时间、模型类型、统计、优化返回结果、容差分解、参数设计和已执行的局部探索等。没有序列化 Python 预测闭包；这是分析报告，不是可加载的模型文件。
- 当前响应的诊断图可导出 PNG 或 SVG。
- 因子、响应、DOE 数据变化后清除旧分析。修改 k 或优化权重时提示原结果属于先前设置，并要求重新生成统计面板，避免核验点混用参数。

## 本轮验证

新增 `test_workbench_analysis.py` 的 12 个测试，独立核对 OLS 系数/标准误/区间、显式留一 PRESS、重复点纯误差/LOF，并检查代理模型统计边界、有限数据描述、可行性优先探索、不可行稳定候选、方差分解、设计点评估、CSV/JSON 导出和数据失效清空。

另外回归验证 13 个代理工作台测试、12 个经典 DOE 测试及 2 个筛选/田口专项测试。结果页在离屏 Qt 中生成预览并检查布局，未操作或替换用户当前运行的软件进程。源码修改需重启软件后生效。


## 界面与独立约束更新

- 左侧项目浏览器已移除。底部消息面板统一显示操作反馈，分隔条可拖动调整高度。
- 优化迭代在后台运行；运行期间优化页锁定以避免重复提交。若其他页面更改了输入，完成后丢弃过期结果。计算期间关闭主窗口会提示等待，避免线程被直接销毁。
- 约束型模式：为每个目标响应填写允许的最大标准差，单位与响应一致。求解时限制各响应 σ ≤ 上限，原有 μ±kσ 性能约束仍然生效。
- 独立约束模式最小化按响应极差归一化、等权汇总的均值损失：望小取 μ，望大取 −μ，望目取与目标中点的绝对偏差。不对损失做 0～1 截断，避免优于试验数据范围的候选出现虚假并列。
- 图中展示各目标 σ / 允许上限；超过 1 表示违反波动约束。手动点核验、局部探索与参数扫描沿用同一波动约束。
- 修复遗传算法父代精英保留和锦标赛选择；可行候选优先，不用优秀目标值抵消约束违反。不再对设计坐标做六位截断后重新评价。
- 筛选与田口仍使用专用分析，不送入连续鲁棒优化器。田口的加性水平推荐仍需确认试验。
- 鲁棒均值和标准差采用独立输入的对角二阶近似，不等价于完整概率可靠度分析。

已知精度限制：旧双盆地测试中，SVR 默认参数的留出 R² 为 0.5422，未达到原测试 0.60 门槛。未降低门槛；页面对 R² 低于 0.60 或非有限值提示检查样本和调整模型。此阈值为软件提示，不是工程验收标准。
