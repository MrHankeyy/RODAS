# 经典 DOE 验证与使用说明

本次改动覆盖方案配置、DOE 生成、响应分析、优化设计和分析报告。修改源码后需要重启软件；不会热更新已经打开的 Python 进程。

## 三种方法对应不同结果

| 方法 | 当前支持 | 优化设计模块输出 |
| --- | --- | --- |
| 筛选 | 全因子、1/2 分数、1/4 分数、PB；中心点、重复、随机顺序和种子 | 各响应高减低主效应、平方效应份额、重点因子图、重复点纯误差、中心点曲率提示、交互混杂提示 |
| 田口 | L4/L8/L12/L16 两水平与 L9/L27 三水平表；内外表独立选择水平；重复、顺序、种子 | 各内表组均值和标准差、各因子水平均值及 S/N、按响应分别给出的候选水平、均值与 S/N 曲线 |
| 响应曲面 | CCD 面心/可旋转/自定义轴值、BBD；中心点、重复、顺序、种子 | 完整二次模型、编码说明、拟合与验证；同一模型进入鲁棒优化、参数设计和容差分析 |

筛选不输出连续最优点。田口候选组合采用主效应可加假设，存在交互作用时尤其需要确认试验；多个目标推荐冲突时不自动合并。纯约束响应仅作描述，不以最大 S/N 代替可行性检验。响应曲面鲁棒优化继续执行已设置的响应目标和约束。

## 回填与结果解释

1. 在业务建模中定义因子、响应的目标/约束角色、望大/望小/望目。固定因子不占 DOE 列，固定值仍写入试验矩阵。
2. 生成方案，导出或复制试验输入，计算每行响应后回填。保留 `Run_ID`；田口还应保留 `内表组号`、`外表组号` 和 `重复组号`。仅有原 `Run_ID` 时可以从当前方案恢复田口分组；编号不能重排编号或重复。
3. 保存响应，进入优化设计点击顶部按钮。筛选显示专用主效应分析，田口显示专用水平均值/S/N 分析，响应曲面进入鲁棒优化工作台。分析完成后停留在结果页，报告同步刷新。
4. 修改因子、响应定义、DOE 数据或配置后，旧分析会失效，需重新计算。缺失或非有限响应不会被悄悄用于经典 DOE 分析。

田口望小采用 `−10 log10(mean(y²))`，望大采用 `−10 log10(mean(1/y²))`，后者要求响应为正。望目采用相对目标上下界中点的均方偏差损失 S/N；这与经典的均值平方/方差 S/N 不是同一公式，界面明确标出“目标偏差损失”。无外表且每组只观测一次时仅比较均值，不能据此评估稳健性。重复相同确定性函数不会凭空产生随机误差。

筛选的平方效应份额不是统计显著性或因果贡献。没有独立重复时不报告主效应 p 值；有重复时的 p 值仍依赖独立同方差等假设，并未作多重比较校正。部分析因和 PB 必须结合混杂说明解释。

CCD 的低/高水平对应编码 ±1；α>1 的轴点会超出它们。无法接受外伸试验点时应选择面心 CCD 或其他适用设计。点型不足以识别完整二次模型时拒绝生成/拟合；交叉验证分折后秩不足时显示不可估计，不再偷偷降阶。纯误差为零时不以 LOF 的虚假 p 值宣称模型充分。

## 修复的主要问题

- 修正四分之一分数设计重复/混杂的生成列，至少需要 5 个因子，并报告实际分辨率。
- 删除无响应时按因子范围编造的筛选排名及报告兜底排名。
- 按每个响应独立计算效应，综合排名使用无量纲份额；不混用不同响应量纲。
- 修正田口无外表时一律最大化均值、多目标只采用第一个结果的问题；增加重复试验及内外表独立水平选项。
- 田口分组使用持久编号，核验观测数量和原设计输入，避免排序/回填错配。
- 响应曲面汇总与优化共用完整二次模型；修正二阶导数漏乘拟合系数的问题。
- 隐藏筛选、田口不适用的连续优化与模型工具；报告按方法展示，输入变化时清除旧结果。

## 验证

新增 `test_classical_doe.py`：12 个测试方法，包含多种参数组合，覆盖全部支持的筛选列正交性和田口正交表两列平衡、已知解析主效应、缺失响应、混合内外表水平、S/N 公式、推荐方向/冲突、排序恢复、固定因子、二次曲面预测和物理单位导数、Qt 配置到分析入口、报告、失效清空，以及响应曲面实际鲁棒工作台。

相关既有验证：13 个代理工作台测试、2 个筛选/田口测试，以及响应曲面、解析鲁棒优化、双盆地鲁棒前沿 3 个函数测试。双盆地解析验证的推荐点约为 `(2.0003, 1.9986)`。

本次没有把此前已知的 SVR 特定双盆地拟合精度问题纳入已修复结论，也没有降低该测试阈值。这些验证证明列出的计算与集成场景通过，不代表任何实际响应函数都能被这些设计准确拟合。
