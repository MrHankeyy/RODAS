# 当前结果报告使用说明

本版本按最新用户要求精简了报告流程，取代此前基于需求 PDF 的操作履历与档案设计。

1. 保存问题定义，配置 DOE 并回填响应。
2. 执行对应方案分析：筛选输出效应与混杂提示；田口输出信噪比和推荐水平；响应曲面或代理模型输出优化候选与统计分析。
3. 在“分析报告”查看当前结果。项目名称、编制人均为选填。
4. 导出 PDF 或 HTML。报告直接使用当前计算结果，不重新训练或优化。

再次计算替换当前结果，不收集操作历史，不提供历史回溯、试验报告切换或档案打开功能。输入改变后需要重新计算。旧版 output/pdf 中带 model/trial/archive 名称的演示文件仅为旧功能验证遗留物，不代表当前界面功能。

底部消息面板统一显示操作成功、提醒、失败和优化迭代进度，支持筛选与清空；消息只在本次会话内显示，最多保留 500 条。

报告仍保留必要的适用范围：模型计算不代表实测确认；约束不可行时不能把返回点作为推荐方案；筛选分析不是连续优化；田口候选水平需要确认试验。

验证覆盖报告不重新拟合、当前结果失效、无历史收集、最小编制信息、HTML 转义和 PDF/HTML 导出。
