# 数值输入框复用实施记录

日期：2026-10-21。

## 用户确认的交互

- 整数保留加减操作，默认增量 1；小数取消按钮、键盘方向键及滚轮加减。
- 整数、小数的手动编辑均在回车或失去焦点后更新，不逐字触发业务联动。
- 整数加减立即生效；生成方案、执行优化／工具、手动核验前主动确认输入，避免读取旧值。
- 保留各字段的上下限、默认值、精度、原生校验、程序回填和业务启用／显示条件。
- 不增加设置持久化。

## 公共实现与接入范围

`frontend/numeric_inputs.py` 提供 `numeric_input` 和 `commit_numeric_inputs`。整数仍返回 `QSpinBox`，小数为 `QDoubleSpinBox` 的轻量子类，兼容现有 `value/setValue/valueChanged/findChildren` 调用。小数滚轮事件交由父级处理，允许滚动页面。

原 20 组整数、14 组小数配置均已接入，覆盖方案配置、四类模型参数、鲁棒优化、优化工具和动态因子核验。原模型局部 `_dspin` 已删除；各页面保留参数含义及联动规则。模型生成前由 `collect_config` 确认，经典方案生成前由配置页确认，优化动作由既有输入检查入口确认，核验在读取设计点前确认。

具有单值／区间等特殊语义的文本框和表格编辑不在本次替换范围。
