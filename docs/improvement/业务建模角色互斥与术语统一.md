# 业务建模角色互斥与术语统一

实施日期：2026-11-03。

- 代理模型任务的目标响应、约束响应勾选加入独占按钮组，切换角色时自动取消另一个选项。业务建模保存仅生成当前选择的单一角色；阈值无效时仍阻止提交，已保存数据不被无效草稿覆盖。
- “响应阈值”改为“响应鲁棒性阈值”，同步表头、上下限悬停、错误提示、术语表和报告。田口任务的“目标值”继续使用原名称与含义。
- 代理模型任务中“设计因子、环境因子”分别改为“设计变量、不确定性参数”。业务导航、新增入口、结果表、遗传算法自动变异概率说明、输入不确定性说明、报告来源和相关错误提示同步更新。田口保留控制/噪声因子，因子筛选保留试验因子。
- 方案配置的中心复合设计、Box–Behnken设计范围列由“低水平、高水平”改为“设计下限、设计上限”。数值列顺序、试验点生成及边界计算不变；悬停保留编码±1与CCD轴点可能超出设置范围的说明。非结构化采样继续使用抽样下限、抽样上限。
- 名称映射不改变内部输入来源枚举、变量标识和计算数据。当前使用说明及DEMO1说明同步更新。
